Installation & Startup

Install the theme package, load its global stylesheet, and initialize GpThemeManager once during browser application startup.

Initialization sets data-gp-theme and data-gp-mode on the document root. The manager also restores persisted choices and follows operating-system changes when mode is system.

TypeScript & JSON Base Theme Architecture

gp-ui uses a 3-tier token hierarchy: Primitives (raw scales), Semantic (contextual Light & Dark tokens), and Components (component styles). Themes are built by extending the master baseTheme with extendTheme().

CSS Variables, Aliases & Lifecycle

Prefer semantic --gp-* variables in authored CSS. Component token paths are flattened to kebab-case, and W3C-style aliases resolve independently for Light and Dark modes.
